# Card Break Website

Hong Kong card break e-commerce platform — Next.js + Supabase + Stripe.

## Phase 0 status

- [x] Next.js + TypeScript + Tailwind scaffold
- [x] Traditional Chinese (default) + English + Simplified Chinese
- [x] Placeholder homepage with clean collectibles-style UI
- [ ] Node.js installed on your machine
- [ ] `npm install` completed
- [ ] Local dev server running
- [ ] GitHub + Vercel deploy (optional for Phase 0)

## Quick start

See **[SETUP.md](./SETUP.md)** for full beginner-friendly instructions.

```bash
cd /Users/amanda/Desktop/card-break-website
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000/zh-Hant](http://localhost:3000/zh-Hant)
